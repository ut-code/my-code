## コレクション `if`、`for` とスプレッド演算子

[[Dart]]のコレクションリテラル内では、要素の生成ロジックとして `if`、`for`、スプレッド演算子を直接埋め込むことができます。

これにより、動的なリスト生成を非常に宣言的かつクリーンに記述できます。
