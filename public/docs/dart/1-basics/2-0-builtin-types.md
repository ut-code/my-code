## 組み込み型と文字列操作

[[Dart]]のすべての値はオブジェクトであり、数値や真偽値も含めて `Object` を継承しています。

主要な組み込み型には、整数 `int`、浮動小数点数 `double`、その共通親型 `num`、文字列 `String`、真偽値 `bool` があります。
