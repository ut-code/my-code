## Dartの特徴（JIT/AOTコンパイル、UI最適化言語）

[[Dart]]は、美しく高速なユーザーインターフェース（UI）を構築するために設計された、オブジェクト指向の型安全なプログラミング言語です。

クライアントサイド（モバイル、Web、デスクトップ）の開発体験を極限まで高めるため、実行基盤や言語構文に独自の工夫が施されています。
