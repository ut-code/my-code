## この章のまとめ

1.  JavaScriptはクラスベースではなく、**[[プロトタイプベース]]**の[[継承]]を行う。
2.  [[オブジェクト]]は隠し[[プロパティ]]（`[[Prototype]]`）を持ち、[[プロパティ]]が見つからない場合にそこを探索する（[[プロトタイプチェーン]]）。
3.  `[[Object.create]](proto)` は、特定の[[プロトタイプ]]を持つ[[オブジェクト]]を直接生成する。
4.  [[コンストラクタ関数]]と [[`new`]] 演算子を使うと、`Func.[[prototype]]` を親に持つ[[インスタンス]]を生成できる。これがJavaなどの「[[クラス]]」に近い振る舞いを模倣する仕組みである。
