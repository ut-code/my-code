## この章のまとめ

  * [[変数]]は [[`const`]] をデフォルトとし、再代入が必要な場合のみ [[`let`]] を使う。[[`var`]] は使用しない。
  * [[プリミティブ型]]は値渡し、[[オブジェクト]]型（配列含む）は参照渡しである。
  * [[`const`]] で宣言した[[オブジェクト]]の中身は変更可能である。
  * 比較には必ず `===`（[[厳密等価演算子]]）を使用し、`==` による暗黙の型変換を避ける。
