## この章のまとめ

1.  **[[`class`]] 構文** は[[プロトタイプ継承]]の[[糖衣構文]]であり、[[`constructor`]] で初期化を行います。
2.  **[[メソッド]]定義** は `function` キーワードが不要で、`get` / `set`（[[ゲッター]] / [[セッター]]）でアクセサを定義できます。
3.  **[[継承]]** は [[`extends`]] を使い、子クラスの[[コンストラクタ]]内では必ず [[`this`]] に触れる前に `[[super]]()` を呼ぶ必要があります。
4.  **[[`static`]]** で[[静的メソッド]]を、**`#`** プレフィックスでハード[[プライベートフィールド]]（外部からアクセス不可）を定義できます。

[[クラス]]構文を使うことで、コードの構造がより明確になり、他の言語の経験者にとっても読みやすいコードになります。しかし、裏側では[[プロトタイプチェーン]]が動いていることを忘れないでください。
